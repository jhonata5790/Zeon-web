# Zeon Web 0.9.9.3 — Chama Mística: base contínua

Agora a Chama Mística possui uma base de energia contínua em toda a largura do banner, composta por três ondas orgânicas e pequenas línguas de fogo sobrepostas. A base é desenhada antes das chamas altas. Os raios ancorados da 0.9.9.2 permanecem sem alterações.

O módulo `zeon-mystic-surface.js` é idêntico em bytes ao do Zeon Windows 0.9.9.3; utiliza o mesmo algoritmo e cores. Não altera o tema Chama Natural, o motor P2P, chats, dados pessoais ou tabelas do Supabase.

Não há migração de banco. Para testes: usar Chama Mística nas duas plataformas e comparar 0%, 35%, 80%, 100% de intensidade, mobile e movimento reduzido.
